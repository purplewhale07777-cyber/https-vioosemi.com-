# VIOOSEMI — Logo Brand Kit

## Approved logo
The approved lockup is stacked: semiconductor chip/circuit emblem above the **VIOOSEMI** wordmark. The wordmark uses a left-to-right **blue → purple → blue** gradient. The vector master is reconstructed as editable paths from the approved raster artwork; it does not depend on an installed font.

## Files in this repository
- `vioosemi-logo-master.svg` — editable path-based vector master with blue–purple–blue gradients.
- `vioosemi-logo-black.svg` / `vioosemi-logo-white.svg` — single-color vector variants.
- `README-brand-guidelines.md` — brand and usage specification.

## Full asset package
The complete ZIP package supplied in the ChatGPT handoff includes transparent full-color, black and white PNGs; 300/600/1200 px web exports; black-on-white and reverse-on-dark previews; RGB EPS and vector PDF; CMYK EPS and CMYK PDF; and a PDF usage guide.

## Typography and licensing
The exact original typeface used by the generated logo artwork is not identified. The delivered vector wordmark is converted to paths, so it has no font dependency. For new editable text that visually complements the logo, **Inter Display ExtraBold** is a suggested substitute only. Inter is distributed under SIL Open Font License 1.1; obtain it from its official project and retain the license when redistributing font files.

## Usage specifications
- Preferred lockup: centered, emblem above wordmark.
- Suggested minimum digital width: **120 px** for the complete stacked logo.
- Suggested minimum print width: **25 mm** for the complete stacked logo.
- Clear space: keep at least **25% of the emblem width** free on every side of the full lockup.
- Use full color on white or very light neutral backgrounds; use the white reverse version on dark, uncluttered backgrounds; use black for monochrome applications.
- Do not stretch, skew, rotate, recolor, add shadows or outlines, change the gradient direction, rearrange the emblem and wordmark, or place the logo on a visually busy background.
- For very small UI placements, use a separately approved simplified emblem-only favicon.

The minimum sizes and clear-space rule are proposed standards for this initial identity system. Review them against actual header and print layouts before formal publication.

## Adobe Illustrator note
The EPS and vector PDF are Illustrator-compatible and can be opened and edited in Adobe Illustrator. A native `.ai` file is not included because the Illustrator proprietary file format is not generated here. To create one, open the SVG or EPS in Illustrator and use **File → Save As → Adobe Illustrator (.ai)**.

## Production note
The vector master is a path-based trace of the approved raster logo, not the original designer's native construction file. It is suitable for normal web and standard print use; inspect contours at the intended large-format output size and request a physical CMYK proof before mass printing.
